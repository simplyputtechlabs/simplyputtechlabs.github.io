Core concepts

The essentials, at a glance.

Start with these foundational ideas. Each one helps explain how modern generative AI systems behave.

CONCEPT 01

Generative AI

AI systems that generate new content—such as text, images, audio, video, or code—based on patterns learned from data.

CONCEPT 02

Large Language Model

A model trained on large amounts of text to process and generate language, often by predicting the next token.

CONCEPT 03

Training vs. inference

Training adjusts a model's parameters using data. Inference is when the trained model produces an answer to an input.

CONCEPT 04

Prompt engineering

Writing clear instructions, context, constraints, and examples to guide a model toward a useful response.

CONCEPT 05

Retrieval-Augmented Generation

RAG retrieves relevant information from external sources and supplies it to a model to help ground its response.

CONCEPT 06

Responsible AI

Think about privacy, bias, safety, reliability, copyright, and human review when using AI systems.

LLM vocabulary

Terminology worth knowing.

Use this quick reference as you read model documentation, tutorials, and research.

TokenA chunk of text—such as a word, part of a word, or punctuation—that a model processes.
Context windowThe amount of tokenized information a model can consider in a single request, subject to its limits.
ParametersLearned numerical values inside a model that influence its outputs.
EmbeddingA numerical representation of content used to capture aspects of meaning or similarity.
TemperatureA generation setting that can affect the randomness of token selection; its effect depends on the system.
HallucinationAn answer that sounds plausible but includes incorrect, unsupported, or fabricated information.
Fine-tuningFurther training a pretrained model on selected data to adapt its behavior for a task or domain.
AI agentA system that uses a model to decide steps and may call tools to pursue a goal.
